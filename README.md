# 📚 Smart AI Study Buddy

An AI-powered learning assistant that helps students learn from PDF documents through summaries, quizzes, flashcards, and interactive chat.

## 🚀 Live Demo
[Try Smart AI Study Buddy](https://smartaistudybuddy-pzbwwhq2spk8bf477hdakt.streamlit.app/)

## ✨ Features
- 📄 Upload and extract text from PDF files
- 📝 Generate AI-powered summaries
- ❓ Create quizzes for self-assessment
- 🗂️ Generate flashcards for revision
- 💬 Ask questions about PDF content
- 📥 Download generated learning materials
- 🔊 Text-to-speech support
- 📈 Track learning progress and history

## 🛠️ Tech Stack
- **Language:** Python
- **Frontend:** Streamlit
- **AI:** Google Gemini API
- **PDF Processing:** PyMuPDF
- **PDF Export:** ReportLab
- **Data Storage:** SQLite

## ⚙️ Run Locally

1. Clone the repository:
   `git clone https://github.com/nivedha0704/SmartAIStudyBuddy.git`

2. Open the project folder:
   `cd SmartAIStudyBuddy`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Create a `.env` file and add your Gemini API key:
   `GEMINI_API_KEY=your_api_key_here`

5. Run the application:
   `streamlit run streamlit_app.py`
